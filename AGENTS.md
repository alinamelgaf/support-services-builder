# Разработка SSB

- Продолжайте работу в локальной ветке `dev`. Сохраняйте завершённые доработки осмысленными коммитами после проверки.
- После завершения доработки обновляйте `docs/UNRELEASED.md`. Записывайте результат, текущий статус проверки и хеш коммита. Обновление журнала может идти отдельным коммитом после доработки.
- Для локальной проверки используйте `http://localhost:4173/`. Проверяйте на синтетических данных.
- Изменения `main`, отправка на GitHub, создание релизов и развёртывание выполняются после явного согласования с владельцем.
- При подготовке релиза переносите в `CHANGELOG.md` только проверенные и одобренные изменения. После публикации снимайте соответствующие пункты с учёта в `UNRELEASED.md`.
