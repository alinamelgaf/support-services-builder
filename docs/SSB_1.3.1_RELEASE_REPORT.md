# Проверка и выпуск SSB 1.3.1

23 ноября 2026 г. · PATCH к опубликованной 1.3.0.

## Состояние

**Версия 1.3.1 опубликована и проверена на https://ssb.melgaf.com/.** CI, повторная проверка release workflow и Pages завершились успешно. GitHub зафиксировал ручное одобрение `public-release` пользователем `alinamelgaf`. Черновик опубликован workflow как стабильный релиз, не Pre-release.

## Фактический состав относительно v1.3.0

Сравнение выполнено с тегом `v1.3.0` (`697762a`). В продукт входят только две согласованные визуальные доработки:

1. Компактная геометрия интерфейса: кнопки 3 px, поля и внутренние панели 4 px, основные разделы и окна 6 px; интервалы действий 4/8 px, между разделами 12 px; основные отступы 14/21 px. Сохранены цвета, названия, расположение функций, рабочая область таблицы 78dvh и области нажатия.
2. Постоянная нейтральная подсказка под предпросмотром палитры: **В режиме «Авто» SSB подберёт более контрастный цвет текста.** Условное жёлтое предупреждение удалено из отображения; алгоритм контрастности, палитра и автосохранение не изменены.

Изменения рабочего кода ограничены CSS, статическим текстом окна палитры и удалением отображения прежнего предупреждения. Импорт, модель предложения, черновики, шаблоны, экспорт Word/Excel, исходники PWA и workflows не изменялись. Дополнены проверки сохранения настроек при обновлении PWA.

В пользовательские CHANGELOG, «Что нового» и Release Notes не включены удаление завершённого локального PWA-стенда, отдельное исправление кавычек и функции 1.3.0. Кавычки «ёлочки» уже присутствовали в исходном предупреждении production 1.3.0. Отчёты обслуживания сохранены как история; незавершённых функций в выпуске нет. Ранее созданный неотслеживаемый аналитический отчёт не включается в коммит.

## Обновление установленного PWA

Прочитаны и сохранены точные публичные файлы production 1.3.0 с SHA-256. Проверка перехода **1.3.0 → 1.3.1** выполнена на одном изолированном HTTPS-origin в каждом браузере, с реальной тестовой регистрацией PWA через браузерный протокол. Проверены установка, отдельное окно, отказ от обновления, повреждённый ответ SW, штатное подтверждённое обновление, офлайн-работа, закрытие и повторный запуск браузера, повторное открытие отдельного окна без переустановки.

Черновик, изменённый параметр, выбранный пакет, включение услуг, личный шаблон, настройки источников и собственная палитра сохранились. Параметры постоянных настроек сравниваются до обновления, после него и после перезапуска. Старая ошибка CacheStorage в Chrome, зафиксированная при обслуживании среды, не повторилась в новых профилях с короткими путями; изменений приложения для её обхода не внесено.

Манифест и код SW неизменны относительно 1.3.0: `id: /`, `start_url: ./`, `scope: ./`, `display: standalone`, URL `manifest.webmanifest`. На рабочем origin идентичность остаётся `https://ssb.melgaf.com/`. Меняются версия и контрольные суммы ресурсов сборки. Схема локального хранения и адрес сайта сохраняются.

Ограничения: реальные ярлыки пользователя в «Пуске»/панели задач и перезагрузка Windows не тестировались; реальная рабочая установка не обновлялась в эксперименте. После выпуска проверить её по инструкции ниже. Формирование документов проверено структурно и браузерным скачиванием; отдельный просмотр в настольных Word/Excel в этой итерации не выполнялся.

## Безопасность и контроль публикации

Штатная проверка 116 публичных файлов и обеих сборок с внешним приватным списком запрещённых данных пройдена. Сканирование новой истории повторено после фиксации кандидата `6e4d54a`: 34 текстовых объекта и сообщения коммитов, совпадений не найдено. В поставку входят только разрешённые файлы и синтетический пример. Тестовые профили, сертификат localhost, частный список проверки, исходные пользовательские выгрузки и локальные черновики не входят в репозиторий или ZIP. MIT и уведомления сторонних библиотек сохранены.

CI и release workflows не менялись. Подтверждено, что `public-release` требует одобрения владельца; включён прежний контролируемый workflow `Publish an approved release`. Тег `v1.3.1` и стабильный черновик Release созданы после успешного CI. Проверено состояние ожидания обязательного одобрения `public-release`; после ручного одобрения владельцем workflow опубликовал Release и развернул Pages. Защита не обходилась. Предыдущий тег и релиз 1.3.0 не удаляются; штатная инструкция отката сохранена.

## Проверка пользователем после публикации

1. В прежнем браузере и профиле откройте установленный SSB обычным ярлыком.
2. Нажмите «Проверить обновления», затем «Установить обновление» и подтвердите перезапуск.
3. Проверьте версию 1.3.1, выбранный пакет, параметры, «Мой шаблон» и собственную палитру.
4. Закройте все окна SSB и снова откройте прежним ярлыком. Приложение должно открыться отдельным окном.
5. Проверьте «Помощь», «Что нового», импорт сохранённого JSON и скачивание документов.

Удалять приложение, ярлыки или данные сайта для штатного обновления не требуется.

Это не проверка реальной установки конкретного пользователя.

Тег, Release и резервные ZIP 1.3.0 сохранены. Инструкция отката актуализирована для этой контрольной версии. Завершённые пункты сняты с учёта в UNRELEASED; локальная dev-среда продолжает работать на localhost:4173. Итоговое обновление документации не меняет приложение, тег или развёрнутые артефакты.
