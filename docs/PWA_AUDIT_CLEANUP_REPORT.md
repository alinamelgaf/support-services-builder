# Очистка временного стенда аудита PWA

23 ноября 2026 г. · Локальная ветка `dev` · Версия приложения остаётся 1.3.0 / 1.3.0-dev.

## Выполнено

| Удалённый компонент | Назначение и основание удаления |
|---|---|
| `Start SSB PWA Audit.cmd` в корне проекта | Локальный неотслеживаемый запускатель. Его единственная команда запускала `../ssb-pwa-identity-qa/manual-stand.mjs`; обычный сервер, сборка, тесты и CI его не вызывали |
| Строка `/Start SSB PWA Audit.cmd` в `.git/info/exclude` | Локальное исключение только для удалённого запускателя. Остальные правила исключения сохранены, `.gitignore` не изменён |

В `docs/PWA_IDENTITY_AUDIT_REPORT.md` сохранены результаты аудита, добавлен статус архивного документа. Старые шаги установки, запуска и переключения временного стенда заменены историческим описанием, ссылка запуска порта 4187 убрана. История проверки и инструкция для рабочего SSB сохранены.

Внутри репозитория других исполняемых компонентов стенда не найдено. Отдельный сервер и его настройки находятся снаружи. Подменённые заголовок HTML, название манифеста и контрольные суммы Service Worker сервер формировал в памяти из двух тестовых сборок, поэтому удалять основной манифест или Service Worker не требовалось.

Проверка ссылок выполнена в коде проекта, scripts, tests, package.json, build.mjs и workflows, а также в связанных внешних сценариях. Имена файлов сами по себе не использовались как основание удаления.

## Сохранено

- `Start SSB Test.cmd`, `scripts/dev-server.mjs`, `scripts/dev-client.mjs` и существующий сервер на `localhost:4173`.
- `build.mjs`, упаковщик, зависимости, конфигурация, все исходники приложения и автоматические тесты, включая `tests/browser.mjs`, `tests/dev-browser.mjs`, сценарии импорта и экспорта.
- Основные `pwa/manifest.webmanifest`, `pwa/sw.js`, иконки и `src/pwa.js`, идентичность PWA и механизм обновлений.
- Оба GitHub Actions workflow, настройки публикации и версия 1.3.0. Никакие действия публикации не выполнялись.
- `.local/node-path.txt` и используемый штатным запуском Node.js. Обнаруженный исполняемый файл в `../auth-experiment/runtime/` является общей зависимостью локального запуска и не относится к удаляемому стенду.
- Отчёты, история Git и отдельный ранее существовавший неотслеживаемый аналитический отчёт. Последний не изменялся и не включался в коммит.
- Установленный Support Services Builder, его ярлыки, реальные профили Chrome/Edge и браузерные данные. Команды очистки их хранилищ и удаления установленных приложений не выполнялись.

## Внешние файлы: найдены, не удалены

Все пути ниже указаны относительно корня репозитория `support-services-builder`.

| Путь | Назначение и рекомендация |
|---|---|
| `../ssb-pwa-identity-qa/Start SSB PWA Audit.cmd` | Вторая копия запускателя внешнего стенда; кандидат на отдельное согласованное удаление |
| `../ssb-pwa-identity-qa/manual-stand.mjs` | Сервер только для `127.0.0.1:4187`, переключение 1.2.0 → 1.2.1 и тестовое имя приложения; кандидат на отдельное удаление |
| `../ssb-pwa-identity-qa/manual-stage.txt` | Сохранённый этап переключения стенда; кандидат на отдельное удаление |
| `../ssb-pwa-identity-qa/launch-windows-shortcut.ps1` | Вспомогательный сценарий прежней проверки реальных ярлыков изолированного профиля. Штатные тесты текущего проекта его не вызывают; оставить до отдельного решения |
| `../ssb-pwa-identity-qa/fixture-build/` | Копия проекта, зависимостей и тестовых сборок, включая HTML, манифест и Service Worker. Использовалась и для прежнего аудита, и как источник обновлённой версии ручного стенда; не удалять по одному названию папки |
| `../ssb-pwa-identity-qa/base-source.zip` | Архив исходной версии для воспроизводимости аудита; сохранён, удаление обсуждать отдельно от исполняемых компонентов |
| `../ssb-1.2.0-qa/published-v1.2.0/` | Архив опубликованной версии, из которого стенд читал исходное состояние. Это исторический материал проверки выпуска; сохранён |

Безопасный следующий шаг при необходимости: отдельно согласовать удаление первых трёх конкретных файлов, убедиться, что порт 4187 не используется, затем удалить только согласованные файлы. Вспомогательный PowerShell-сценарий, архив и копию сборки рассматривать отдельно, сохраняя отчёты и материалы, необходимые для воспроизводимости. Не удалять внешнюю папку целиком вместе с её содержимым без такого просмотра. Профили и хранилища браузеров в этот список не входят.

На проверке порт 4187 не слушался. Запускать стенд для его удаления не потребовалось. За пределами репозитория файлы стенда, сборок и пользовательские данные не изменялись.

## Ограничение проверки Chrome

Локальный автоматический PWA-тест Chrome сообщил сначала `Unexpected internal error` при открытии CacheStorage, затем `InvalidAccessError: Entry already exists` при записи. Повтор с новым профилем, более короткими путями и HTTPS не устранил ошибку. Причина в рамках технической очистки не установлена. Код приложения и тестов для обхода ошибки не менялся; результат не отмечен как успешный.

Импорт и экспорт в Chrome прошли. Полная PWA-регрессия в Edge прошла. Основные PWA-файлы и восемь ресурсов сборки совпадают с опубликованной версией, поэтому очистка не внесла изменений в механизм обновлений. Отдельное исследование ошибки CacheStorage Chrome в эту задачу не включалось.

## Статус

Техническая очистка внутри проекта выполнена. Внешние компоненты оставлены по ограничению пользователя и требуют отдельного решения. Версия, рабочий сайт, main, теги и релизные процессы не изменялись. Итог заносится в `docs/UNRELEASED.md`, изменения фиксируются только в локальной ветке dev.
