# Проверка Support Services Builder 1.1.0

Версия подготовлена как кандидат на первую публикацию. Для испытаний использованы синтетические данные и локальный HTTPS-стенд с путём `/support-services-builder/`.

| Сценарий | Результат |
| --- | --- |
| Сборка | В чистой копии выполнена установка по lockfile. SHA-256 всех производственных файлов и обоих ZIP совпали. |
| Импорт и настройки | Проверены три источника Confluence, пагинация, базовые и локальные настройки, выбор пакета и состав услуг. Подтверждено чтение прежнего формата настроек. |
| Документы | Excel и Word сформированы на синтетических данных. Проверены листы, разделы, ссылки и параметры. |
| Установка и запуск | Chrome 157.0.8103.39 и Edge 157.0.4341.42 прошли проверку манифеста, Service Worker, установки и удаления PWA через браузерный протокол. В Chrome подтверждено открытие установленного приложения. В Edge браузерный протокол в режиме без видимого окна не подтвердил отдельный запуск. |
| Подготовка обновления | Стенд имитировал публикацию нового комплекта статических файлов. Проверены ручной запрос, обнаружение после восстановления сети, ожидание подтверждения и отказ при нарушенной контрольной сумме. При ошибке исходная версия оставалась доступна. |
| Восстановление | После обновления восстановились каталог, выбранный вариант, параметры, видимость услуг, клиент, вводный текст, настройки менеджера и конфигурация источников. После закрытия браузера тот же черновик открылся без сети. |
| Конфликт записи | Устаревшая вкладка получила предупреждение при попытке записать поверх предложения, сохранённого другой вкладкой. |
| Справка и описание версии | Окно «Что нового» показало номер тестового выпуска. «Помощь» открыла иллюстрированное руководство после офлайн-перезапуска. PDF из четырёх страниц проверен постранично. |
| Автоматические проверки | 11 тестов Node.js прошли, включая проверку заполненности описания релиза и ожидания записи черновика. Обе схемы GitHub Actions проверены actionlint 1.7.12. |

Установка через меню «Пуск» в пользовательской сессии Windows, выполнение workflow на GitHub и развёртывание Pages подлежат проверке после разрешения владельца. Тестовый выпуск распространялся только локальным стендом. Подробности проверки данных и зависимостей приведены в [отчёте о безопасности](SSB_SECURITY_FINAL_REPORT.md).
