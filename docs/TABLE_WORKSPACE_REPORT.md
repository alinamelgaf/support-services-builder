# Рабочая область таблицы и управление Confluence

Изменения выполнены в локальной ветке `dev`. Версия приложения остаётся 1.2.2 / 1.2.2-dev. Публикация и изменение рабочего сайта не выполнялись.

## Изменения

- Максимальная высота области «Сравнение вариантов» увеличена с `68vh` до `78dvh`, с резервным `78vh`. Высота автоматически пересчитывается при изменении окна. Небольшой каталог не растягивается до максимума.
- Сохранены внутренние вертикальная и горизонтальная прокрутки, закреплённые заголовки, отметка «Предложение» и выделение выбранного пакета. Размеры строк, поля параметров и порядок столбцов не изменены.
- В настройках предложения остались «Источники Confluence» и «Загрузить JSON» в прежнем порядке.
- «Очистить загруженные данные» перенесена в левую часть нижней строки окна источников. Справа находятся «Очистить настройки источников» и «Сохранить источники локально».
- Максимальная ширина окна источников увеличена с 800 до 1040 px, чтобы три кнопки помещались в одну строку. На узких экранах группы переносятся, а само окно прокручивается. Удаление оформлено существующими второстепенными красными кнопками.
- Используется прежний обработчик очистки и прежнее подтверждение. Окно источников остаётся открытым. После операции фокус остаётся внутри него; сообщение о результате прокручивается в видимую область, в том числе на узком экране.
- Обновлено руководство пользователя.

Механизмы импорта, хранения, применения стандарта и личного шаблона, палитры, экспорта и PWA не перерабатывались.

## Результаты проверки

Прошли 37 автоматических тестов и сборки production и dev. Браузерные проверки выполнялись в Chrome и Edge в отдельных тестовых профилях, только на синтетических данных.

| Окно браузера | Высота области таблицы |
|---|---|
| 1440 × 700 | 546 px |
| 1440 × 1000 | 780 px |
| 1440 × 1200 | 936 px |
| 375 × 700 | 546 px |
| 320 × 640 | ≈499 px |
| 844 × 390 | ≈304 px |

При окне 1440 × 1000 и каталоге из 26 учебных услуг видно девять полных строк вместо восьми при прежней высоте. Высота строк сохранена. Все размеры проверены последовательным изменением одного окна без перезагрузки.

| Сценарий | Результат в Chrome и Edge |
|---|---|
| Вертикальная прокрутка и закреплённая шапка | Заголовки сохраняют положение; фон шапки непрозрачный |
| Нижние строки и переход от прокрутки таблицы к странице | Последняя строка доступна; прокрутка у границы таблицы не запирает страницу |
| Узкий экран | Нет горизонтального переполнения страницы и окна источников; горизонтальная прокрутка таблицы открывает последнюю колонку |
| Чекбоксы, параметры, описание услуги, выбор пакета | Работают; отметка и выделение переключаются |
| Автосохранение | Параметр и выбранный пакет восстанавливаются после перезагрузки |
| Кнопки окна источников | Слева очистка каталога, справа очистка настроек и сохранение; на широком экране одна строка |
| Отмена обеих очисток, × и Escape | Данные и настройки не изменяются |
| Очистка каталога | Каталог и связанные данные удалены из черновика; экспорт отключён; окно источников остаётся открытым |
| Повторное открытие и продолжение старой REST-выгрузки | Старый каталог не восстанавливается |
| Независимость очисток | Шаблон и палитра сохранены; очистка каталога сохраняет источники, очистка источников сохраняет каталог и черновик |
| Ошибка IndexedDB / localStorage | Нет ложного успеха; прежние данные остаются доступны |
| Узкий экран после очистки | Сообщение о результате видно внутри окна источников |
| Повторный импорт без настроек, дополнительные источники | Работают; диагностика некорректных и неоднозначных данных сохранена |
| Word и Excel | Браузерный экспорт и проверки содержания документов, включая представления SLA, пройдены |

Использованы сценарии `table-workspace-browser.mjs`, `clear-data-browser.mjs`, `sources-browser.mjs` и `sections-browser.mjs`. Пройдена проверка публичных исходников и обеих поставок с приватным списком запрещённых данных. Реальные выгрузки, черновики и настройки в изменения не добавлялись.

## Ограничения

Проверки выполнялись автоматизированно в установленных Chrome и Edge. Перезапуск проверен закрытием и повторным открытием страницы в том же тестовом профиле; перезагрузка Windows не выполнялась. Физические сенсорные устройства не проверялись. На узких экранах горизонтальная прокрутка таблицы остаётся необходимой для доступа ко всем шести колонкам. Блокирующих проблем не обнаружено.
