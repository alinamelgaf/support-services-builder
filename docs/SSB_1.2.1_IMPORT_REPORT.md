# SSB 1.2.1 — загрузка Confluence JSON без настройки источников

12 ноября 2026 г. · Локальная ветка `dev` · Коммит `93aaef2`

## Изменения

- На первом запуске можно сразу нажать **Загрузить JSON**. Блок настроек источников свёрнут. После импорта показаны количество услуг и распознанные разделы.
- Карточки определяются по полям Page Properties. Базовая конфигурация, вводные тексты, SLA, уровни критичности, допущения и ограничения и глоссарий определяются по таблицам. Те же поля и заголовки используются в действующих парсерах. SLA и справочник критичности можно загрузить как с общей, так и с разных страниц.
- Настроенные метки помогают выбрать из нескольких подходящих страниц при наличии полных метаданных. Однозначная структура распознаётся даже с отсутствующими, неполными или устаревшими метками. Если выбор остаётся неоднозначным, SSB показывает ID и названия конкурирующих страниц. Остальные корректные разделы доступны.
- Сохранены проверка полноты REST, переход по страницам, дедупликация и импорт старого формата каталога. Для ссылок внутри выгрузки приоритет имеет базовый адрес из REST-ответа. Механизмы формирования Word и Excel сохранены.
- В кандидат 1.2.1 также вошла ранее подготовленная фиксация идентификатора PWA из коммита `dce0db4`. Описание выпуска сформировано из CHANGELOG, руководство обновлено.

| Chrome и Edge | В чистом профиле нажата кнопка **Загрузить JSON** и выбран полный синтетический REST-ответ без метаданных. Распознаны 6 карточек и все реализованные разделы. Проверены повторный импорт, диагноз неоднозначности с ID страниц, выбор по настроенной метке, восстановление черновика и выгрузки Word и Excel. Сценарий пройден в рабочей и тестовой сборках на локальных адресах. |
| Автономная поставка и обновление PWA | Chrome и Edge загрузили каталог из файла без предварительных настроек. В отдельных профилях проверен переход 1.2.0 → 1.2.1 по локальному HTTPS с повторным запуском отдельного окна и восстановлением черновика. |
| Публичная поставка | Рабочая, автономная и тестовая сборки собраны. Сканер с частным списком маркеров проверил исходники, тесты и публичные сборки. Учебные данные синтетические. Аудит зависимостей не обнаружил известных уязвимостей. Для обоих ZIP проверены состав и SHA-256. |

Проверки использовали синтетические выгрузки. Файл из рабочего Confluence можно проверить на локальной сборке до выпуска. При первом запуске ожидаются каталог и список распознанных разделов после одного выбора готового JSON.
