# Обновления Support Services Builder

Версия видна в верхней строке. Релизный процесс собирает сайт из конкретного тега `vX.Y.Z`, сверяет его с `package.json` и готовит файлы GitHub Pages после публикации одобренного релиза. Обычные коммиты проходят CI и не обновляют сайт.

Браузер обнаруживает новый Service Worker штатным механизмом. Проверку также можно запустить кнопкой **Проверить обновления**. Обновление предварительно загружает статические файлы и проверяет их целостность. Если загрузка не завершилась, активная версия продолжает работать. Когда версия подготовлена, кнопка меняется на **Установить обновление**. [ServiceWorkerRegistration.waiting](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/waiting)

Применение обновления запрашивает подтверждение и сообщает, если есть черновик или загруженный JSON. После подтверждения перезагружается текущая вкладка. Прочие уже открытые вкладки сохраняют состояние в памяти до их перезагрузки. Браузер также может активировать ожидающую версию после закрытия всех старых вкладок. Сохранённые настройки менеджера и метки источников остаются в локальном хранилище того же origin. Текущий черновик и данные Confluence, находившиеся в памяти, потребуется загрузить заново.

Чтобы обновить автономный ZIP, скачайте настройки из текущей версии, распакуйте новую поставку и при необходимости импортируйте настройки. Автономная версия запускается из файла и обновляется вручную.
