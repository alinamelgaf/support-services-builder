# SSB — выравнивание заголовков таблиц Word и Excel

12 ноября 2026 г. · Локальная ветка `dev` · Коммит `dcb1d56`

## Изменение

- В Word заголовки столбцов отдельных таблиц SLA, уровней критичности и глоссария теперь выравниваются по центру по обеим осям. Таблицы «Состав вариантов поддержки» и сравнительная матрица SLA уже использовали это выравнивание, в том числе для строки «Предложение».
- В Excel все экспортируемые таблицы уже использовали горизонтальное и вертикальное центрирование заголовков с переносом текста. Это подтверждено для всех листов, включая «Описание услуг» и «Допущения и ограничения», и для строки «Предложение».
- В Word «Описания услуг» и «Допущения и ограничения» сохраняют текстовое представление. Для таблиц обоих форматов сохранены шрифты, заливки, выделение выбранного пакета и выравнивание данных.

## Проверка

| Проверка | Результат |
|---|---|
| Автоматические тесты | 21 из 21. Новый тест проверяет выравнивание заголовков по обеим осям, перенос и строку «Предложение» в Word и Excel для девяти сочетаний трёх пакетов и трёх представлений SLA. |
| Экспорт в Chrome и Edge | Для каждого браузера проверены три представления SLA на синтетических данных. Внешние запросы при проверке не обнаружены. |
| Настольные Word и Excel | Открыты и визуально проверены шесть файлов, по одному на каждый формат и представление SLA, с выбранным Extended. Длинные подписи и русские названия пакетов отображаются полностью, строка «Предложение» в сравнительных таблицах находится над выбранным пакетом. |
| Локальная сборка | Сборка в режиме production и проверка публичных файлов прошли. |

Проверка выполнена на синтетических данных. Настольный просмотр проведён с выбранным Extended, Standard и Managed Service дополнительно покрыты автоматической проверкой свойств экспортируемых файлов.

Изменения сохранены только в локальной ветке `dev`.
