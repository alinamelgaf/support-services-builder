# Отчёт о локальной среде SSB

11 ноября 2026 г.

Исходники находятся на том же компьютере Windows, где открывается браузер. `Start SSB Test.cmd` запускает Node.js 24 и существующий сборщик проекта. Сервер слушает `127.0.0.1:4173` и открывает [http://localhost:4173/](http://localhost:4173/). Для этого режима используются уже установленные зависимости проекта.

Сервер наблюдает за исходниками и пересобирает версию `1.1.0-dev` после изменений. Страница и ресурсы отдаются без браузерного кеширования. При открытии вкладки во время сборки отображается состояние сборки. Уже открытая вкладка предлагает загрузить новую сборку после записи черновика. При ошибке текущая вкладка сохраняет свою работу, а новый запрос страницы получает сообщение о состоянии сборки с кодом HTTP 503.

## Фактические проверки

| Проверка | Результат |
|---|---|
| Двойной щелчок в Проводнике Windows | Открылся Chrome с вкладкой «SSB — Тестовая версия». Повторный запуск использовал тот же сервер. Адрес прослушивания проверен через `netstat`. |
| Интерфейс и автоматическая пересборка в Chrome и Edge | Видны метка «ТЕСТОВАЯ» и суффикс `-dev`. Временная правка шаблона появилась по тому же адресу без перезапуска сервера. |
| Безопасное обновление в Chrome и Edge | При несохранённой правке настроек источников обновление остановилось. После отмены этой правки обновлённая сборка загрузилась, черновик восстановился. |
| Ошибка сборки и восстановление в Chrome и Edge | Ошибка в исходном JavaScript отобразилась в открытых вкладках. Новое открытие вернуло HTTP 503. После исправления сервер пересобрал приложение, черновики восстановились. |
| Импорт и документы в Chrome и Edge | Загружен синтетический каталог. Внутри сгенерированных Excel и Word проверены идентификатор услуги и значение из восстановленного черновика. Сетевые запросы приложения остались на локальном адресе. |
| Изоляция в Chrome и Edge | Настройки источников, состав по умолчанию и черновики раздельны. При совместном размещении по разным путям одного origin рабочий Service Worker продолжил обслуживать рабочую сборку. Тестовая сборка не добавила Service Worker. |
| Регрессии рабочей версии | 11 автоматических тестов прошли. В Chrome и Edge прошли проверки автономного режима, PWA, офлайн-работы и обновлений. Валидатор Release Notes прошёл. |
| Рабочий сайт | SHA-256 пяти опубликованных файлов `index.html`, `app.js`, `app.css`, `sw.js` и `manifest.webmanifest` совпали до и после работ. Все 15 файлов двух локальных рабочих сборок побайтно совпали с файлами проверенных архивов 1.1.0. |
| Проверка публичных файлов | Сканирование отслеживаемых файлов и рабочих сборок прошло с локальным списком закрытых маркеров. |

## Границы проверки

Импорт проверен на синтетическом JSON. Испытание команды остановки `Ctrl+C` из окна запуска отдельно не проводилось. Для текущей установки используется имеющийся подписанный переносимый Node.js. Если он будет перемещён, понадобится обновить локальный путь или установить Node.js по инструкции.

Вкладка с открытым предложением обновляется по кнопке **Загрузить новую сборку**. Файлы самого локального сервера и сценария запуска вступают в силу после его перезапуска. Для совместного размещения тестовой и рабочей сборок на одном origin нужны разные пути. Текущий локальный адрес выделен тестовой сборке.

Изменения сохранены в локальной ветке `dev`. Рабочая ветка `main` осталась на коммите `47ed975`. Состав и статус правок записаны в [журнале](UNRELEASED.md).
