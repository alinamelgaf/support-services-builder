# Support Services Builder 1.2.2

14 ноября 2026 г. · Коммит `a9dd88a`

В выпуск вошли две согласованные доработки. Импорт Confluence пропускает неподдерживаемые страницы и оставляет пустые или отсутствующие необязательные разделы недоступными. Для заполненных таблиц с некорректными данными сохраняется диагностика. Светло-голубое уведомление о различиях настроек показывает активную конфигурацию и ID услуг.

| Проверка | Результат |
|---|---|
| Регрессия | 27 автоматических тестов. В Chrome и Edge проверены импорт синтетических данных, повторная загрузка, конфигурации менеджера и Confluence, Word и Excel во всех форматах SLA и восстановление черновика. |
| Обновление PWA | На локальном HTTPS проверен переход с опубликованной 1.2.1 на 1.2.2 в Chrome и Edge. Установка, идентификатор и черновик сохранились. После перезапуска приложение открылось в отдельном окне. |
| Безопасность | Аудит зависимостей не выявил известных уязвимостей. Проверены изменения и история, публичные исходники и сборки с частным списком маркеров. Архивы CI совпали по SHA-256 с проверенной поставкой. |
| Документация | Обновлены история изменений, руководство и инструкция импорта. «Что нового» и русские Release Notes сформированы из записи 1.2.2 в CHANGELOG. |

Этап проверки релизной сборки прошёл со второй попытки. В первом запуске браузерный тест не дождался уведомления об ошибке обновления PWA. Повтор выполнен на том же теге. Архивы, русское описание и 11 файлов GitHub Pages побайтно совпали с проверенной поставкой.

После ручного одобрения в окружении `public-release` сборка, публикация релиза и развёртывание GitHub Pages завершились успешно. Русское описание и контрольные суммы архивов на GitHub совпадают с проверенной поставкой. [Релиз v1.2.2](https://github.com/alinamelgaf/support-services-builder/releases/tag/v1.2.2)

Рабочий сайт показывает 1.2.2 по HTTPS. Восемь основных ресурсов сайта побайтно совпали с артефактом GitHub Pages. Проверены номер версии, содержание раздела «Что нового» и отсутствие тестовых элементов. [Рабочий SSB](https://ssb.melgaf.com/)

Журнал неопубликованных изменений актуализирован в локальной ветке `dev`. Тестовая сборка 1.2.2-dev доступна для дальнейшей работы. [Локальная тестовая среда](http://localhost:4173/)
