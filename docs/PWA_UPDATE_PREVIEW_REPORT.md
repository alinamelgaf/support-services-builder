# Кнопки SSB и тестовые сценарии обновления PWA

12 ноября 2026 г. · Локальная сборка `1.1.0-dev`

Коммит реализации в `dev` — `adc523a`.

## Интерфейс

**Помощь**, **Что нового** и **Проверить обновления** выровнены по правому краю верхнего блока и используют прежний стиль. На узком экране кнопки переносятся. Если браузер предлагает первоначальную установку PWA, кнопка **Установить приложение** появляется перед ними.

В настройках источников Confluence поле называется **Вводные тексты**. Сохранённые метки и загрузка JSON работают по прежней схеме. В составе документа пункт по-прежнему называется **Вводный текст**.

## Проверка в тестовой сборке

1. Откройте [localhost:4173](http://localhost:4173/) и нажмите **Загрузить новую сборку**, если есть уведомление о ней.
2. Нажмите **Проверить обновления**. Появится статус проверки и затем результат **Новая версия не найдена**.
3. В поле **Тестовый ответ PWA** выберите **Доступна новая версия** или **Ошибка проверки**. Нажмите **Проверить обновления** ещё раз.
4. При имитации доступной версии кнопка **Установить обновление** показывает пояснение о тестовом режиме. Она не меняет версию и не перезагружает страницу.

Учебные сообщения начинаются с «Имитация PWA». Для имитации используются локальные данные. Команда **Загрузить новую сборку** относится к локальному серверу разработки и по-прежнему сохраняет черновик перед перезагрузкой.

## Проверки

- 18 автоматических тестов прошли.
- В Chrome и Edge проверены обе сборки на ширине 1280 и 320 пикселей, переход в справку, окно «Что нового» и состояния кнопки проверки обновлений.
- В Chrome и Edge локальная копия рабочей сборки успешно прошла обычную проверку и установку обновления с восстановлением черновика. Исправлено кратковременное появление кнопки «Установить обновление» при первой установке PWA.
- Тестовая сборка не содержит Service Worker и команды его активации. Имитация доступного обновления оставила готовую локальную сборку доступной для загрузки. После применения этой сборки учебный черновик восстановился.
- Проверки рабочей сборки выполнены на локальной копии. Опубликованный PWA в проверке установки не участвовал.
