# Безопасность Support Services Builder

- Загружайте JSON через файловый диалог. Разбор, обработка, черновик и экспорт выполняются в браузере. Ссылка Confluence открывает настроенный менеджером адрес в отдельной вкладке.
- Сохранённые настройки и каталог находятся в браузерном профиле. Размещайте приложение с рабочими данными на доверенном HTTPS-адресе. Хранилище изолируется адресом сайта и профилем браузера. Другой код на том же origin может иметь к нему доступ.
- Приложение использует локальные ресурсы и ограничивает программные сетевые соединения через CSP. Service Worker кеширует только статические файлы выпуска с контрольными суммами. Аналитика, телеметрия и внешние CDN отсутствуют.
- Входная HTML-разметка преобразуется в ограниченную модель текста. Сценарии, внешние изображения и опасные ссылки из JSON не исполняются. Ссылки на страницы Confluence исключаются из экспортируемых документов.
- Для очистки черновика и локальных настроек используйте настройки данных сайта в браузере. Сначала скачайте нужные документы и файл локальных настроек. Удаление установленного приложения и очистка данных сайта могут быть отдельными действиями браузера.
- В CI используйте только синтетические данные. Перед публичным push дополните проверку частным списком корпоративных маркеров вне проекта. Храните рабочие выгрузки, документы и учётные данные вне репозитория.

Команды и порядок проверок приведены в [инструкции публикации](GITHUB_PUBLICATION.md). Результаты 1.2.0 приведены в [отчёте о выпуске](SSB_1.2.0_RELEASE_REPORT.md).
