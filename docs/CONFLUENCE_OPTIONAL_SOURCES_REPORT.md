# SSB — обработка необязательных источников Confluence

14 ноября 2026 г. · Локальная ветка `dev` · Коммит `2db822e`

В 1.2.1 страница без содержимого могла попасть в список ошибок до определения типа источника. Настроенные метки также могли дать предупреждение об отсутствующем необязательном разделе. Теперь импорт классифицирует страницы по поддерживаемой структуре и при необходимости по настроенным пользователем меткам. Страницы без признаков поддерживаемых источников пропускаются. Это распространяется на «Матрицу RACI» без привязки к названию страницы, ID или корпоративной метке.

Пустые и отсутствующие необязательные разделы получают пояснение в блоке «Состав документа» и остаются недоступными. Для распознанных заполненных таблиц сохранены сообщения о неверных заголовках, неполных данных и неоднозначности. Для карточек услуг, базовой конфигурации и полноты REST-выгрузки действуют отдельные проверки. Таблица базовой конфигурации только с заголовками считается ошибкой.

| Сценарий | Результат |
|---|---|
| Отсутствует необязательный источник | Раздел недоступен. В списке импорта нет ошибки или предупреждения из-за его отсутствия. |
| Пустой источник | Пустая страница, таблица только с заголовками и незаполненный шаблон отключают необязательный раздел. Заполненная копия того же источника доступна. |
| Неподдерживаемый источник | Страницы без содержимого и с неподдерживаемой структурой пропущены как с пустыми, так и с заполненными настройками. |
| Некорректный реализованный раздел | Сообщение указывает проблему с таблицей. Остальные корректные разделы доступны. |
| Все источники заполнены | Каталог, базовая конфигурация и дополнительные разделы загружены. Word и Excel сформированы. |
| Повторный импорт и черновик | После загрузки исправленной выгрузки прежняя ошибка исчезла из уведомления и списка импорта. После перезагрузки черновик восстановился без прежней ошибки. |

Прошли 27 автоматических тестов. Браузерный сценарий пройден в Chrome и Edge на локальных рабочей и тестовой сборках с синтетическими данными. Сборка и аудит публичных файлов с частным списком маркеров прошли. Проверка выполнена локально в `dev`.
