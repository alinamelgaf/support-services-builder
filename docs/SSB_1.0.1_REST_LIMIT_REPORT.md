# Проверка лимита REST в Support Services Builder 1.0.1

Кнопка **Получить актуальные данные** открывает `/rest/api/content/search` с `limit=50` и `expand=body.storage,metadata.labels`. Если Confluence возвращает `_links.next`, пользователь сохраняет следующий JSON и добавляет его к первой части.

Все 9 автоматических тестов прошли. Для проверки лимита использованы синтетические ответы REST с карточками услуг, базовой конфигурацией и вводными текстами.

| Записей в ответах | Что подтвердилось |
| --- | --- |
| 28 | Из одного JSON импортированы 26 карточек, базовая конфигурация и вводные тексты. |
| 50 | Из одного JSON импортированы 48 карточек и обе страницы настроек. |
| 51 | При наличии `_links.next` первые 50 записей ожидают продолжения. После импорта второй части с `start=50` загружаются 49 карточек и обе страницы настроек. |

В Chrome и Edge проверены ссылка с `limit=50` и импорт одного JSON с 28 записями через интерфейс PWA. Браузерные тесты также проверили автономную сборку.

Ответ рабочего Confluence в этой проверке был недоступен. Чтобы подтвердить получение текущих 28 страниц одним файлом, откройте ссылку из версии 1.0.1 в авторизованном браузере. В полном ответе должны быть 28 записей в `results` и отсутствовать `_links.next`. После импорта проверьте, что отображаются 26 карточек, стандарт и вводные тексты.
