# Настраиваемая палитра документов SSB

Модель хранения и действия окна впоследствии упрощены: [актуальный отчёт об автосохранении](PALETTE_AUTOSAVE_REPORT.md). Ниже сохранены результаты первоначальной реализации.

В разделе «Сравнение вариантов» появилась кнопка «Палитра документа». Диалог содержит два цветовых блока, три режима текста в каждом и предпросмотр таблицы. Рабочие цвета SSB сохранены. Для подбора HEX доступны внешние ссылки Get Color и Adobe Color. Они открываются по нажатию, без передачи настроек палитры.

## Палитры и контраст

| Параметр | Базовая палитра | Своя палитра в примере |
|---|---|---|
| Основной фон заголовков | `#234C5E` | `#F7DC94` |
| Текст на основном фоне | `#FFFFFF`, по умолчанию | `#000000`, авто |
| Фон заголовков выбранного пакета и метки «Предложение» | `#00AD21` | `#683CA0` |
| Текст на фоне выбранного пакета | `#FFFFFF`, по умолчанию | `#FFF0DC`, свой |
| Заливка ячеек выбранного пакета | `#E0F5E4` | `#EDE8F4` |

Изменение поля базовой палитры переводит диалог в режим «Своя». Возврат к базовой палитре восстанавливает предустановленные значения. До исправления некорректного HEX предпросмотр и экспорт используют последний корректный цвет. Для фиксации локально нужно исправить все видимые HEX-поля. В черновик записываются только корректные значения.

Предпросмотр и экспортёры используют `src/export-palette.js`. Он смешивает цвет предложения с белым для заливки выбранных ячеек и основной цвет с белым для чередования строк. У почти белой заливки выбранных ячеек яркость приглушается, чтобы столбец был различим. Для цветного названия листа внутри таблицы Excel и строки клиента основной оттенок при необходимости затемняется на белом фоне. Обычный текст, шрифты и размеры сохраняются.

В режиме «Авто» программа сравнивает контраст чёрного и белого и использует более контрастный вариант. Порог предупреждения для обоих заголовков — 4,5:1. Базовое сочетание `#00AD21` и белого даёт около 3,00:1, поэтому в базовом режиме видно предупреждение. В Word и Excel это сочетание сохраняется как задано. [W3C, требования к минимальному контрасту](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

## Сохранение

- Палитра текущего предложения сохраняется в том же черновике IndexedDB. Старый черновик без палитры открывается с базовыми цветами. Повторная загрузка каталога сохраняет текущую палитру.
- «Зафиксировать локально» сохраняет настройки для новых предложений через то же браузерное хранилище, которое SSB использует для настроек. Тестовая и рабочая сборки используют разные ключи. После подтверждённого сброса базовая палитра применяется к текущему и новым предложениям. [Отчёт о сохранении и сбросе](PALETTE_CONFIRMATION_REPORT.md)
- «Новое предложение» заменяет один текущий черновик только после подтверждения. SSB сохраняет загруженный каталог и активную конфигурацию пакетов, сбрасывает клиентские поля и правки предложения и применяет локальную палитру. Если локальная палитра отсутствует, применяется базовая.

## Примеры

Оба набора сформированы в SSB из одного синтетического каталога. В обоих вариантах выбран Extended и включены сравнительная матрица SLA, уровни критичности, допущения и ограничения, глоссарий.

| Палитра | Word | Excel |
|---|---|---|
| Базовая | `SLA-Extended-base.docx` | `SLA-Extended-base.xlsx` |
| Своя | `SLA-Extended-custom.docx` | `SLA-Extended-custom.xlsx` |
