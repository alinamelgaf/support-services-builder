# Support Services Builder 1.2.1 — проверка выпуска

12 ноября 2026 г.

Готовый Confluence REST JSON загружается без предварительной настройки источников. Сопоставление использует структуру страниц. Ручные настройки доступны для ссылки на выгрузку и уточнения неоднозначных источников. Явный идентификатор PWA сохраняет адрес и идентичность существующей установки.

| Проверка | Результат |
|---|---|
| Состав выпуска | В четырёх коммитах только распознавание источников, совместимый идентификатор PWA, тесты и документация. Повторная локальная сборка побайтно совпала с ранее подготовленными архивами 1.2.1. |
| Автоматические тесты | 24 из 24. Проверены загрузка с пустыми настройками, повторный импорт, неоднозначные источники, пагинация и экспорт. |
| Chrome и Edge | На синтетическом JSON проверены импорт, ручное уточнение источников и Word и Excel. Установленные PWA обновились с 1.2.0 до 1.2.1 по локальному HTTPS и открылись в отдельном окне после перезапуска. Идентификатор и черновик сохранились. |
| Настольный Office | Word и Excel открыли синтетические выгрузки всех трёх представлений SLA. |
| Аудит | Проверены все четыре новых коммита, их метаданные, публичные исходники и сборки с частным списком маркеров. Аудит зависимостей не выявил известных уязвимостей. Архивы CI и workflow, Release Notes и все 11 файлов артефакта GitHub Pages совпали с проверенным кандидатом. |

GitHub опубликовал стабильный релиз после ручного одобрения в окружении `public-release`. Сборка, выпуск и GitHub Pages завершились успешно. Описание на русском и контрольные суммы обоих опубликованных ZIP совпали с проверенными файлами. [Релиз v1.2.1](https://github.com/alinamelgaf/support-services-builder/releases/tag/v1.2.1)

Рабочий сайт отдаёт версию 1.2.1 по HTTPS. Восемь проверенных ресурсов побайтно совпали с поставкой, элементы тестовой среды отсутствуют. Манифест сохраняет идентификатор `https://ssb.melgaf.com/`, адрес запуска и отдельное окно. Chrome и Edge на рабочем сайте загрузили синтетический JSON без настройки источников и сформировали Word и Excel. [Рабочий SSB](https://ssb.melgaf.com/)
