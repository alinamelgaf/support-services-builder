# Установка и первый запуск SSB

## Автономная версия

1. Распакуйте ZIP целиком в обычную папку. Откройте `index.html` в Chrome или Edge.
2. Чтобы попробовать интерфейс, нажмите **Загрузить JSON** и выберите `examples/demo-confluence.json`. Для рабочих данных используйте согласованную выгрузку из Confluence. Настройки источников для готового файла необязательны.
3. Выберите вариант предложения и отредактируйте состав и параметры. При наличии вводного текста для выбранного пакета его можно включить в документ. Скачайте Excel или Word.
4. Если настройки понадобятся снова, нажмите **Зафиксировать локально**, подтвердите действие и скачайте файл настроек. При недоступном хранилище приложение прямо сообщает, что настройки остались только в открытой вкладке.

В режиме `file://` постоянство браузерного хранилища зависит от браузера и пути файла. Для переноса между компьютерами или папками используйте **Скачать настройки** и **Загрузить настройки**. Для автономного обновления распакуйте новый ZIP и загрузите ранее скачанные настройки.

## Установка PWA

1. Откройте HTTPS-адрес, предоставленный администратором.
2. Если появилась кнопка **Установить приложение**, нажмите её и подтвердите установку. В Chrome также можно воспользоваться кнопкой установки в адресной строке или меню. В Edge откройте меню **Приложения** и выберите установку сайта как приложения, если пункт доступен.
3. После первого успешного открытия SSB кеширует файлы приложения. Проверьте офлайн-режим повторным открытием с отключённой сетью. Импорт сохранённого JSON и экспорт документов доступны офлайн. Для получения новой выгрузки потребуется доступ к Confluence.

Настройки и черновик привязаны к профилю браузера и адресу размещения. При перезагрузке приложение восстанавливает последнее сохранённое предложение и обработанный каталог. В другом профиле или на другом адресе загрузите каталог и резервный файл настроек. [Документация Chrome по PWA](https://developer.chrome.com/docs/devtools/progressive-web-apps)

### Ярлыки в Windows

В рабочем профиле Chrome или Edge откройте [ssb.melgaf.com](https://ssb.melgaf.com/) и выберите **Открыть в приложении**, если браузер показывает эту команду. Из открывшегося окна можно закрепить SSB на панели задач Windows. В Edge установленные приложения также видны на странице `edge://apps`. [Справка Microsoft об установленных приложениях и ярлыках](https://learn.microsoft.com/microsoft-edge/progressive-web-apps-chromium/ux)

Если ярлык «Пуска» открывает вкладку, сначала запустите рабочий SSB указанным способом. При наличии нескольких одноимённых записей проверьте браузер, профиль и адрес приложения перед тем, как открепить старую запись. В Chrome на странице `chrome://apps` проверьте параметр **Открывать в окне**, если он доступен для SSB. Для обновления достаточно уже установленного рабочего приложения.
