# Установка и первый запуск SSB

## Автономная версия

1. Распакуйте ZIP целиком в обычную папку. Откройте `index.html` в Chrome или Edge.
2. Чтобы попробовать интерфейс на учебных данных, настройте три демонстрационные метки из инструкции импорта и загрузите `examples/demo-confluence.json`. Для рабочих данных используйте только локально согласованную выгрузку.
3. Выберите вариант предложения, отредактируйте состав, параметры и вводный текст. Скачайте Excel или Word.
4. Если настройки понадобятся снова, нажмите **Зафиксировать локально**, подтвердите действие и скачайте файл настроек. При недоступном хранилище приложение прямо сообщает, что настройки остались только в открытой вкладке.

В режиме `file://` постоянство браузерного хранилища зависит от браузера и пути файла. Для переноса между компьютерами или папками используйте **Скачать настройки** и **Загрузить настройки**. Для автономного обновления распакуйте новый ZIP и загрузите ранее скачанные настройки.

## Установка PWA

1. Откройте HTTPS-адрес, предоставленный администратором.
2. Если появилась кнопка **Установить приложение**, нажмите её и подтвердите установку. В Chrome также можно воспользоваться кнопкой установки в адресной строке или меню. В Edge откройте меню **Приложения** и выберите установку сайта как приложения, если пункт доступен.
3. После первого успешного открытия SSB кеширует файлы приложения. Проверьте офлайн-режим повторным открытием с отключённой сетью. Импорт сохранённого JSON и экспорт документов доступны офлайн. Для получения новой выгрузки потребуется доступ к Confluence.

Настройки привязаны к профилю браузера и адресу размещения. В другом профиле или на другом адресе загрузите скачанный файл. Сами JSON-выгрузки остаются у пользователя и загружаются заново после перезагрузки приложения. [Документация Chrome по PWA](https://developer.chrome.com/docs/devtools/progressive-web-apps)
