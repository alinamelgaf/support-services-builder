# Проверка безопасности публичной поставки SSB 1.0.0

Подготовлена отдельная поставка из выбранных исходников браузерного конструктора. Локальный репозиторий начинается с нового базового коммита и не содержит прежней истории или удалённого адреса. Исходники настроены для будущей публикации. Проверка выполнялась локально, GitHub не использовался для размещения кода или сборок.

## Проверка состава

- Из исходного проекта перенесены парсер карточек, редактор, модель предложения, оформление и экспорт. Встроенные пакеты конкретной организации заменены нейтральными пустыми значениями. JSON для примера генерируется из синтетического тестового набора.
- В новом проекте отсутствуют старые выгрузки, документы, скриншоты, конфигурации организации, средства авторизации и артефакты их тестирования. Адрес, пространство и метки Confluence задаются пользователем локально.
- Проверены отслеживаемые исходники, документация, тесты, конфигурация, lockfile, производственные HTML, JS, CSS, манифест, Service Worker и файлы лицензий. Сканер проверяет пути, распространённые форматы секретов и допустимость адресов в коде и примерах. Дополнительно применён частный список известных корпоративных маркеров вне репозитория. Результат пройден без совпадений. Сканер не печатает содержимое совпадений.
- Поставка использует списки разрешённых файлов. Состав архивов и CRC проверены после упаковки. Развёртываемый сайт содержит статические ресурсы приложения. ZIP исходников содержит только новый отслеживаемый набор файлов.

## Хранение и передача данных

| Поток | Поведение |
| --- | --- |
| Получение JSON | Кнопка открывает сконфигурированный REST-адрес Confluence новой вкладкой. Браузер использует штатную авторизацию Confluence. Настройки запроса уходят только в открываемый пользователем адрес. |
| Импорт и экспорт | Пользователь выбирает JSON вручную. Приложение обрабатывает его в памяти, а Excel и Word создаёт как локальные файлы. |
| Хранилище | `localStorage` содержит явно сохранённые настройки менеджера и настройки источников. Черновик предложения и выгрузка REST остаются в памяти вкладки. |
| PWA | Кеш Service Worker содержит только перечисленные статические ресурсы. Целостность ресурсов проверяется при загрузке новой версии. |
| Ссылки | Ссылки в деталях карточки открываются только по действию пользователя. Ссылки на Confluence исключаются из модели экспорта по источнику и типовым путям. В Excel кликабельны внутренние ссылки между листами. |

У обеих сборок `connect-src 'none'`, нет аналитики, внешних шрифтов и CDN. При испытании импортированная разметка с `<script>` и удалённым изображением была разобрана как данные. В Chrome и Edge при автономном импорте, просмотре карточек и экспорте не наблюдалось HTTP-запросов. В PWA-прогоне браузерные запросы приложения ограничились GET к собственному тестовому origin. При отдельном нажатии на ссылку Confluence или явно выбранную ссылку из карточки произойдёт навигация на этот адрес.

## Зависимости и выпуск

Версии ExcelJS, docx, htmlparser2, JSZip, esbuild и Playwright закреплены в lockfile. Исходный аудит обнаружил известные уязвимости в транзитивном `uuid` и сборочном `esbuild`. После обновления до `uuid` 11.1.1 для ExcelJS и `esbuild` 0.28.1 `pnpm audit --audit-level low` не сообщил об известных уязвимостях. В дереве остались устаревшие транзитивные пакеты ExcelJS. Лицензии включены в сборки.

Workflow CI использует синтетические данные. Действия GitHub закреплены по SHA. Workflow выпуска по умолчанию отключён переменной репозитория и требует ручного запуска на основной ветке с версионным тегом. Публикация релиза и Pages разделены по окружениям. Перед первым размещением владелец должен проверить рабочий diff, прогнать частный скан и настроить правила одобрения. [Официальная документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

Проверка корпоративных строк покрывает известные маркеры и проверяемый состав файлов. Для использования с рабочими данными учитывайте, что `localStorage` доступно другим страницам того же origin. Для PWA с конфиденциальной локальной конфигурацией используйте выделенный доверенный HTTPS-origin. Автономная поставка доступна для работы из локального файла.
