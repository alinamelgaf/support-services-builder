# Получение и импорт данных Confluence Data Center

1. Откройте Confluence в своём браузере и выполните штатный вход.
2. В SSB раскройте **Настройки источников Confluence**. Укажите базовый адрес с контекстным путём, если он есть, и метки нужных источников. Ключ пространства вводите, если все эти источники лежат в одном пространстве. Сохраните настройки локально.
3. Нажмите **Получить актуальные данные**. В новой вкладке откроется read-only запрос `/rest/api/content/search` с CQL, `limit=50` и раскрытием `body.storage,metadata.labels`. Сохраните исходный JSON через браузер. Если браузер сохраняет оформленную HTML-страницу вместо JSON, скопируйте отображаемый JSON целиком в текстовый файл UTF-8 с расширением `.json`.
4. Если в ответе есть `_links.next`, откройте указанный путь в авторизованном Confluence и сохраните следующую страницу. Для относительного пути добавьте только недостающую часть базового адреса или контекста. Повторяйте до последней страницы. При изменениях каталога во время выгрузки лучше начать с первого ответа.
5. Нажмите **Загрузить JSON** и выберите все файлы либо добавляйте их по одному. SSB ждёт непрерывный диапазон с начала выгрузки, проверяет заявленное количество при его наличии и исключает повторы по ID страницы. Пока комплект неполный, предыдущий рабочий каталог остаётся доступен. Кнопка **Начать новую выгрузку** очищает только ожидающие страницы.

Запрос открывается как обычная навигация браузера. SSB читает сохранённые файлы через файловый диалог, поддерживает прямой `results[]` и обёртку `results[].content`. При несовпадении меток или отсутствии `metadata.labels` проверьте ответ и параметры раскрытия. Результат зависит от прав менеджера в Confluence и состава страниц, доступных запросу. [Confluence Data Center REST API](https://developer.atlassian.com/server/confluence/confluence-rest-api-examples/)

## Форматы страниц

| Источник | Что читает SSB |
| --- | --- |
| Каталог | Карточки Page Properties с полями «ID услуги», «Наименование», «Описание услуги», «Условия предоставления», «Основная услуга». |
| Базовая конфигурация | Одна таблица с колонками «ID услуги», «В документ», Standard, Extended, Managed Service. «Карточка услуги» справочная и при сопоставлении пропускается. `+` включает, `-` исключает, текст задаёт параметр включённой услуги. «В документ» принимает `+` или `-` независимо от пакетов. |
| Вводные тексты предложений | Одна таблица «Вариант поддержки» и «Вводный текст» со строками Standard, Extended и Managed Service. Поддерживается также одна строка текста под тремя заголовками вариантов. Сохраняются абзацы, поддерживаемые выделения, списки и ссылки. |
| SLA и уровни критичности | Две обычные таблицы на одной странице. Матрица содержит «Код критичности», «Уровень поддержки», «Время реакции», «Время восстановления сервиса», «Время предоставления временного решения», «Время предоставления постоянного решения» и «Время ответа». Нужны 12 сочетаний кодов 10, 20, 30, 80 с тремя пакетами. Справочник содержит «Код», «Наименование», «Краткое описание», «Полное описание» для кодов 10, 11, 12, 20, 21, 22, 30, 31, 32, 80, 90. |
| Допущения и ограничения | Одна обычная таблица «Раздел» и «Формулировка». Допустимые разделы — «Допущения» и «Ограничения». |
| Глоссарий | Одна обычная таблица «Термин RU», «Term ENG» и «Определение RU». Английский термин может быть пустым. |

При отсутствии строки конфигурации услуга исключена из пакетов и включена в документ. Отсутствующий в каталоге ID и дублирующиеся строки помечаются в результатах импорта. При наличии ранее применимого стандарта он сохраняется до получения корректной базовой конфигурации. Каждая дополнительная таблица проверяется отдельно. Причина недоступности указана рядом с разделом и в результатах импорта. Пункт «Матрица RACI» зарезервирован. Существующий JSON-формат `schemaVersion: 1` загружает только карточки.

После импорта **Применить стандарт Confluence** применяет последнюю корректную базовую конфигурацию. **Зафиксировать локально** сохраняет состав, параметры и видимость услуг. **Восстановить локальные настройки** возвращает сохранённый слой менеджера. Услуги, которых не было в локальном снимке, берут значения из Confluence. При расхождении слоёв панель показывает затронутые услуги и сохраняет текущие правки до решения менеджера. Состав документа и представление SLA сохраняются с черновиком предложения.

## Учебный файл

Для `examples/demo-confluence.json` укажите `demo_catalog`, `demo_defaults`, `demo_intros` в первых трёх полях меток. Адрес и пространство для импорта сохранённого файла можно оставить пустыми. Все страницы, ссылки и условия в этом файле искусственные.
