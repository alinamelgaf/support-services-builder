# Получение и импорт данных Confluence Data Center

## Загрузка готового JSON

1. Скачайте выгрузку из Confluence в авторизованном браузере.
2. В SSB нажмите **Загрузить JSON**. Если выгрузка разбита на страницы, выберите все файлы или добавьте их по одному. Если в ответе есть `_links.next`, сохраните продолжение до последней страницы.
3. Сверьте количество услуг и распознанные разделы. В сообщениях импорта указаны страницы с неподходящей структурой и конкурирующие страницы одного источника.

Адрес Confluence, ключ пространства и метки для готового файла необязательны. SSB поддерживает страницы напрямую в `results[]` и в обёртке `results[].content`. Для распознавания требуется содержимое страницы в `body.storage.value`. Программа сверяет полноту набора с начала выгрузки, учитывает заявленное количество записей и исключает повторы по ID страницы. Пока комплект неполный, прежний каталог остаётся доступен. Кнопка **Начать новую выгрузку** очищает ожидающие страницы.

## Настройки источников

Раскройте **Настройки источников Confluence**, чтобы сформировать ссылку **Получить актуальные данные**. Укажите базовый адрес с контекстным путём и метки нужных страниц. Ключ пространства вводите, если все источники находятся в одном пространстве. Ссылка открывает запрос `/rest/api/content/search` с CQL, `limit=50` и раскрытием `body.storage,metadata.labels` в новой вкладке. Сохраните ответ как JSON в UTF-8. [Confluence Data Center REST API](https://developer.atlassian.com/server/confluence/confluence-rest-api-examples/)

Если подходят несколько страниц, оставьте нужную в выгрузке или уточните выбор одной настроенной меткой. Для сравнения меток у конкурирующих страниц нужен полный `metadata.labels`. Если содержимое однозначно, устаревшая или отсутствующая метка не мешает загрузке.

## Форматы страниц

| Источник | Что читает SSB |
| --- | --- |
| Каталог | Карточки Page Properties с полями «ID услуги», «Наименование», «Описание услуги», «Условия предоставления», «Основная услуга». |
| Базовая конфигурация | Одна таблица с колонками «ID услуги», «В документ», Standard, Extended, Managed Service. «Карточка услуги» справочная и при сопоставлении пропускается. `+` включает, `-` исключает, текст задаёт параметр включённой услуги. «В документ» принимает `+` или `-` независимо от пакетов. |
| Вводные тексты | Одна таблица «Вариант поддержки» и «Вводный текст» со строками Standard, Extended и Managed Service. Поддерживается также одна строка текста под тремя заголовками вариантов. Сохраняются абзацы, поддерживаемые выделения, списки и ссылки. |
| SLA и уровни критичности | Две обычные таблицы на одной или разных страницах. Матрица содержит «Код критичности», «Уровень поддержки», «Время реакции», «Время восстановления сервиса», «Время предоставления временного решения», «Время предоставления постоянного решения» и «Время ответа». Нужны 12 сочетаний кодов 10, 20, 30, 80 с тремя пакетами. Справочник содержит «Код», «Наименование», «Краткое описание», «Полное описание» для кодов 10, 11, 12, 20, 21, 22, 30, 31, 32, 80, 90. |
| Допущения и ограничения | Одна обычная таблица «Раздел» и «Формулировка». Допустимые разделы — «Допущения» и «Ограничения». |
| Глоссарий | Одна обычная таблица «Термин RU», «Term ENG» и «Определение RU». Английский термин может быть пустым. |

При отсутствии строки конфигурации услуга исключена из пакетов и включена в документ. Отсутствующий в каталоге ID и дублирующиеся строки помечаются в результатах импорта. При наличии ранее применимого стандарта он сохраняется до получения корректной базовой конфигурации. Каждая дополнительная таблица проверяется отдельно. Причина недоступности указана рядом с разделом и в результатах импорта. Пункт «Матрица RACI» зарезервирован. Существующий JSON-формат `schemaVersion: 1` загружает только карточки.

После импорта **Применить стандарт Confluence** применяет последнюю корректную базовую конфигурацию. **Зафиксировать локально** сохраняет состав, параметры и видимость услуг. **Восстановить локальные настройки** возвращает сохранённый слой менеджера. Услуги, которых не было в локальном снимке, берут значения из Confluence. При расхождении слоёв панель показывает затронутые услуги и сохраняет текущие правки до решения менеджера. Состав документа и представление SLA сохраняются с черновиком предложения.

## Учебный файл

Загрузите `examples/demo-confluence.json` без предварительной настройки. Все страницы, ссылки и условия в этом файле искусственные.
