# Управление источниками Confluence в SSB

Первым рабочим разделом страницы стали «Настройки предложения». Справа от заголовка расположены «Новое предложение», «Источники Confluence» и «Загрузить JSON». На широком экране группа занимает одну строку, на узком переносится с сохранением порядка. Основной странице достаточно краткого статуса загрузки, подробная сводка перенесена в диалог.

## Окно источников

«Источники Confluence» открывает окно со сводкой загруженного каталога, результатом проверки полноты выгрузки, распознанными разделами и диагностикой. Все прежние поля, подсказки, ссылка получения данных и действие очистки ожидающих страниц доступны здесь. Окно поддерживает прокрутку, закрытие через × и Escape, ввод с клавиатуры и возврат фокуса к кнопке открытия.

Закрытие окна сохраняет введённые поля. Для сохранения источников между запусками используется прежняя кнопка «Сохранить источники локально». «Загрузить JSON» открывает выбор файла непосредственно с основной страницы. Для готового файла предварительная настройка источников необязательна.

## Статус импорта

| Состояние | Отображение |
|---|---|
| Каталог ещё отсутствует | Нейтральная строка «Данные Confluence не загружены» |
| Загрузка прошла полностью | Зелёная строка с фактическим количеством услуг и карточек |
| Импорт содержит предупреждения | Янтарная строка с количеством услуг и указанием открыть источники |
| Часть данных содержит ошибки | Красная строка с количеством импортированных услуг и указанием ошибок |
| Файл не принят или выгрузка неполная | Сообщение об ошибке последней загрузки. При наличии прежнего каталога строка дополнительно показывает количество сохранённых услуг |

Сводка и последняя ошибка хранятся вместе с существующим черновиком. Повторный корректный импорт заменяет диагностику последней загрузки. Для прежних черновиков количество карточек восстанавливается из существующей сводки, если она доступна. При отсутствии старой сводки строка показывает только подтверждённое количество услуг.

## Кнопки

Синяя заливка используется у «Загрузить JSON», «Скачать Excel» и «Скачать Word». Обычные вспомогательные действия, включая обе кнопки «Зафиксировать локально», получили общий нейтральный фон с обводкой и тёмно-синим текстом. Подтверждение сброса палитры сохраняет специальное опасное оформление.

## Проверка

- Прошёл 31 автоматический тест. Собраны рабочая и тестовая версии.
- В Chrome и Edge проверены первый запуск, прямой выбор JSON, загрузка всех реализованных источников, сохранение полей, закрытие и повторное открытие окна, восстановление источников и черновика после перезагрузки страницы.
- На синтетических данных проверены ошибка чтения файла, повторный неудачный импорт с сохранением каталога, загрузка по частям, предупреждение о повторе страницы, некорректный SLA и одна ошибочная карточка услуг. Проверены отсутствие ошибки при пустых и нереализованных необязательных источниках и устранение прежней диагностики после корректного импорта.
- В обоих браузерах проверены ширины от 320 до 1440 px, прокрутка диалога, открытие клавишей Enter, закрытие через Escape и возврат видимого фокуса. Горизонтального переполнения страницы и окна источников в этих сценариях нет.
- Прежние браузерные сценарии автономного запуска, обновлений PWA, настройки пакетов, черновиков, палитры, импорта и экспорта Word и Excel пройдены. Проверка публичных файлов и сборки пройдена.

В рабочем коде использованы прежние парсеры и хранилища. Изменения коснулись расположения элементов, классов кнопок и отображения состояния импорта. На скриншотах показаны синтетический каталог и демонстрационные настройки источников.
