# Безопасность публичной поставки Support Services Builder 1.1.0

## Данные и сетевые запросы

- Каталог Confluence разбирается в браузере. Черновик содержит обработанный каталог, выбранный пакет, изменения услуг и вводный текст. Он сохраняется в IndexedDB, а настройки менеджера и источников — в локальном хранилище того же профиля.
- Приложение и справка используют CSP с `connect-src 'none'`. Service Worker загружает только статические ресурсы своего адреса и проверяет их SHA-256. При ошибке проверки действующий кеш остаётся доступен.
- На тестовом HTTPS-стенде программные запросы приложения ограничились GET к адресу стенда. Тела запросов отсутствовали. В автономном сценарии импорт и экспорт прошли без HTTP-запросов.
- В синтетический JSON были включены сценарий и внешнее изображение. Проверка подтвердила, что они не выполнялись и не загружались. В сгенерированных Excel и Word проверено исключение ссылок на учебный Confluence.
- Запись в черновик проверяет ревизию. При конфликте открытых вкладок приложение показывает ошибку и сохраняет уже записанное предложение. Обновление ждёт завершения записи.

## Проверка поставки

- Сканирование охватило исходники, тесты, конфигурацию, иллюстрации, документацию, PWA и автономную сборку. Частный список известных корпоративных маркеров использован локально. Сканирование не обнаружило совпадений.
- В архиве исходников находятся отслеживаемые файлы нового проекта. В сборках включены только разрешённые статические файлы, инструкция и синтетический пример в автономном ZIP. Архивы проверены после упаковки.
- Аудит зафиксированных зависимостей прошёл без известных уязвимостей на момент проверки. В готовом браузерном пакете ExcelJS отдельно обнаружена встроенная копия uuid 8.3.2, которую обычный аудит lockfile не видит. Сборка добавляет проверку границ по GHSA-w5hq-g745-h8pq и проверяет её присутствие в поставке. Экспорт Excel повторно проверен в браузере. Сборочный Markdown-парсер используется для документации. [Бюллетень uuid](https://github.com/uuidjs/uuid/security/advisories/GHSA-w5hq-g745-h8pq)
- Публикация в GitHub Actions привязана к ручному запуску, основному коммиту, проверенному тегу и черновику GitHub Release. Номер и пользовательское описание валидируются до выкладки. Разрешения на запись разделены между релизом и Pages. [Развёртывание GitHub Pages через Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-actions)

Проверка проводилась на синтетических данных. Корпоративный JSON, учётные данные и частный список маркеров хранятся вне публичной поставки. Рабочий браузерный профиль должен использовать доверенный origin. Лицензию исходников выбирает владелец.
